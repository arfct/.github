# Artifact Primer

This repo holds Artifact's org-wide defaults — issue and PR templates, the org profile, and the **Artifact Primer**: the standards and process that apply across all Artifact projects.

| Doc | Description |
| --- | --- |
| [Standards](primer/standards.md) | Code style, commits, and repo conventions for consistent, self-documenting projects |
| [Tools](primer/tools.md) | The tools Artifact builds with, grouped by area |
| [Deployment](primer/deployment.md) | Where Artifact software runs — hosting targets, app stores, and domains |
| [Linear](primer/linear.md) | How Artifact tracks work in the `arfct` Linear workspace |
| [Bugs](primer/bugs.md) | The bug lifecycle: report, triage, fix, verify |
| [Collaboration](primer/collaboration.md) | Defaults for a small team that scale as contractors and collaborators join |
| [AI agents](primer/agents.md) | Conventions and boundaries for agents contributing alongside humans |

Private counterpart material — brand assets, accounts, and anything not safe for a public repo — lives in `arfct/internal`.
